# Sprint Plan

Two-week sprints. Each sprint corresponds to an iteration in the project's **Sprint** field. Dates are planning targets and can be adjusted at sprint planning.

| Sprint | Dates | Goal | Milestone(s) |
|--------|-------|------|--------------|
| Sprint 1 | 2026-11-16 → 2026-11-29 | Project Foundation and Architecture | Project Foundation |
| Sprint 2 | 2026-11-30 → 2026-12-13 | UI/UX and Authentication | UI/UX Design, Authentication and Backend |
| Sprint 3 | 2026-12-14 → 2026-12-27 | Learning Dashboard and Courses | Learning Core |
| Sprint 4 | 2026-12-28 → 2027-01-10 | Interactive Learning | Interactive Exercises |
| Sprint 5 | 2027-01-11 → 2027-01-24 | Audio, Tifinagh and Gamification | Audio and Tifinagh, Gamification |

## Sprint 1: Project Foundation and Architecture

**Goal:** Establish the technical foundation and approve the product architecture.

Planned work: complete the PRD · define MVP scope · define technical architecture, navigation structure and Firebase architecture · define development standards and the GitHub workflow · initialize the React Native TypeScript project · configure the application structure · create the Firebase project · define the initial Firestore collections.

**Expected deliverables:** approved PRD, technical architecture documentation, a working React Native project, a connected Firebase environment and an initial database schema.

## Sprint 2: UI/UX and Authentication

**Goal:** Establish the visual identity and user authentication system.

Planned work: Adobe XD design system (brand identity, palette, typography, components) · onboarding, splash, auth and dialect-selection designs · React Navigation, state management, theme tokens, env variables and testing framework · Firebase Authentication and Firestore configuration · registration, login, logout, password recovery · user profile · dialect selection.

## Sprint 3: Learning Dashboard and Courses

**Goal:** Deliver the first functional learning experience.

Planned work: dashboard, course and lesson designs · learning dashboard · course listing and details · course/module data structures and database services · lesson navigation · course progression display · Firestore security rules and user roles · Storage configuration.

## Sprint 4: Interactive Learning

**Goal:** Deliver the core educational experience.

Planned work: vocabulary data model and library · quiz interface design · multiple choice, word matching and translation exercises · answer validation, scoring and feedback · lesson completion.

## Sprint 5: Audio, Tifinagh and Gamification

**Goal:** Introduce the distinctive learning features.

Planned work: audio storage and player · word pronunciation · native-speaker recordings · Tifinagh alphabet and letter recognition · XP · daily streaks · achievements and achievement interface.

## Sprint 6: Testing and MVP Release

**Goal:** Prepare the MVP for initial users.

Planned work: unit and integration testing · authentication, navigation, audio and Tifinagh rendering tests · Firestore security testing · linguistic content validation · Android and iOS testing · critical bug fixing · performance optimisation · release documentation.

## Post-MVP backlog

Sentence construction and fill-in-the-blank exercises, flashcards and spaced repetition, sentence pronunciation and playback speed, FCM notifications, daily challenges, statistics, and the Cultural Discovery epic.

## Sprint tracking

- Each sprint's scope is visible in the **Current Sprint** view.
- Sprint review notes and retrospective actions are recorded as comments on the sprint's milestone issues or as new issues.
